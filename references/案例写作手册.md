# 案例写作手册：从材料到中文工商管理论文

本手册把文献中的写作动作转为可以复用的方法。复用对象是研究与论证的组织方式，不是参考案例的事实、模型名称或结论。配套文件为《AI执行流程》、期刊专题、逐文献提取记录与复用验收记录。

> 模板版本：V3训练归纳版。保留前两轮772份训练记录；第三轮实际审阅244/244。总语料1131份PDF、15660页；本轮新27份留出冻结前未参与语义归纳。历史88份保留原版本首次验收。配套34张段落功能卡、13张理论角色卡。

## 1. 先辨认你手中的案例

“有故事”与“有研究材料”是两件事。开始写作前，用以下五个问题组织材料。

| 问题 | 可检查的输出 | 写作中的作用 |
| --- | --- | --- |
| 出现了什么值得解释的现象？ | 具体行为、变化、差异或矛盾及来源 | 引言中的实践问题 |
| 哪些事实已经明确？ | 事件、引语、数据与来源表 | 案例叙述与证据 |
| 解释对象是什么？ | 分析单位、时间范围、待解释关系 | 研究问题与设计 |
| 现有理论如何解释？ | 真实文献中的解释与边界 | 文献对话与理论作用 |
| 材料还能支持什么判断？ | 证据—概念—解释链及反例 | 案例发现与贡献 |

时间阶段、分析单位和机制单元分别记录。一篇纵向论文可以按机制组织发现，也可以按历史阶段组织发现；它们不是同一层次的分类。索菲亚研究按前提、基础、机制、结果组织发现，而凤登环保研究在各阶段重复比较认知、投资与能力。

依据：`d31e644b5640c4f4a`，PDF p4、p7；`d0cd3b426ac9973b6`，PDF p3–4。

## 2. 从现象到研究问题：四个写作动作

1. **展示具体管理现象。** 交代谁在什么情境下做了什么，出现了什么变化或矛盾。
2. **解释现象为什么值得研究。** 说明它涉及哪种管理关系，不只写“具有重要意义”。
3. **定位已有解释及其不足。** 指明对话的研究领域、分析层次与尚需解释的过程。
4. **提出问题与本文的解决路径。** 让研究对象、材料、方法与问题对应。

### 卡片：实践张力转为解释问题

- 功能：把报道性的现象转为研究问题。
- 输入：至少两项不容易同时解释的事实、对应理论文献。
- 动作：展示张力 → 检查已有解释 → 指定未解释的关系 → 提问。
- 改写句式：在【情境】中，【现象 A】与【现象 B】同时出现。已有研究从【视角】解释了【内容】，但【具体过程或条件】仍需解释。因此，本研究关注【明确问题】。
- 来源示例：芯片企业研究从“断链”预期与技术突破的现实张力进入机制问题；农民创业研究从支持、规模与绩效之间的矛盾进入问题。
- 依据：`db67d8eb93aafb9e5`，PDF p1；`d4fd7a65191a69909`，PDF p1。
- 适用边界：真实文献没有证明该缺口时，把它写成待核查的问题；不能复制参考论文的缺口为新领域的缺口。

## 3. 理论不是文章中的一个必填名词

先明确理论承担什么作用，再选择理论名称。

| 理论作用 | 在文章中的位置 | 必须回答的问题 | 示例 |
| --- | --- | --- | --- |
| 帮助提出问题 | 引言、文献回顾 | 原理论解释了什么，哪里出现张力？ | 管理认知与跨组织能力问题 |
| 规定观察与比较维度 | 理论基础、研究设计 | 研究者具体观察什么？ | 自我效能感、拼凑与绩效的比较 |
| 解释案例发现 | 案例分析、讨论 | 什么材料支持哪种关系？ | 认知、投资、能力的过程解释 |
| 作为贡献对话对象 | 讨论、理论贡献 | 相对原解释新增什么条件或关系？ | 双元能力研究的新增条件 |

同一理论可以承担多个作用。若同时使用研究框架和最终机制模型，分别说明两者任务。初始框架说明准备如何观察；最终模型说明材料分析得到了什么。最终模型不能仅把初始框架换一种图形再宣布创新。没有形成新模型的研究，不必为模板增画模型。

依据：索菲亚 `d31e644b5640c4f4a`，PDF p4、p15、p17；农民创业 `d4fd7a65191a69909`，PDF p2、p4；凤登环保 `d0cd3b426ac9973b6`，PDF p2、p4。

### 理论使用卡片

为候选理论填写：解释对象、分析层次、可观察材料、反例、与其他解释的差别、在文章中的角色。只出现理论关键词而没有这些连接时，理论还没有进入论证。

## 4. 选择发现的组织路线

以下是依据训练文献观察提炼的路线；具体模板适用时仍须检查材料。

### 路线 A：按时间阶段解释变化

适合材料包含可以追踪的变化、关键事件与阶段差异的研究。先说明分期依据；在每个阶段保持相同的分析维度。

**章节骨架**：问题 → 理论与研究设计 → 阶段依据 → 各阶段事实及解释 → 跨阶段关系 → 模型与讨论。

**阶段段落链**：阶段情境 → 关键事件/引语 → 同一组概念的变化 → 阶段结果 → 与下一阶段的联系。

凤登环保论文在三个阶段中重复认知、数绿投资与绿色动态能力的分析维度。阶段数量来自该案例历史，不是未来案例必须填写“三阶段”的理由。

过程可以包含反馈、阶段内循环与共时变化，不总是单向线性。浙江中烟分别呈现阶段内循环与阶段间提升，快手与咪咕研究讨论不同过程共时发生。先判断关系是顺序、反馈还是并行，再选择过程图。

依据：`d0cd3b426ac9973b6`，PDF p3–4、p10；`d668a9c140650377e`，PDF p10；`dcbf65d007208d00e`，PDF p10。

### 路线 B：按主题或机制单元组织发现

适合围绕概念内涵、管理思想、跨主体关系或作用机制组织发现。时间线提供背景，发现章节围绕主题任务展开。

**章节骨架**：现象与理论问题 → 研究设计 → 前提/基础 → 机制/过程 → 结果与边界 → 理论对话。

**机制段落链**：本节解释对象 → 多来源事实 → 概念归纳 → 关系解释 → 本节小结与下节问题。

索菲亚研究用前提、基础、机制、结果组织发现，并用数据结构表连接原始证据与概念层次。

依据：`d31e644b5640c4f4a`，PDF p7–8。

**概念辨析与思想主题。** 不必把所有案例写成成长史或阶段机制。手边资源研究按情境、实践特征、相近概念和边界展开；海信研究区分技术思想的形成与其进入战略行动的作用。复用前分别检查概念定义、思想表达、组织行为与作用的证据。语录只证明表达，不能单独证明组织已经照此行动。

依据：`de8c25bd494bfee40`，PDF p2、p4–5、p7–8；`d8b0ac4c8aa606f95`，PDF p3–4、p8–9。

### 路线 C：多案例比较

先完成案例内分析，再用共同维度比较案例。共同维度可以来自既有理论，也可以在资料与理论迭代中形成；必须解释形成依据。

**章节骨架**：问题 → 案例选择与比较逻辑 → 案例内分析 → 跨案例相同/不同 → 解释条件与关系 → 模型与讨论。

**比较段落链**：提出共同维度 → 并列事实 → 指出相同与差异 → 检查解释与反例 → 归纳条件。

农民创业论文使用逐项/差别复制与变量比较；芯片企业研究通过一阶、二阶编码组织跨案例发现。两种写法不能直接混用为未经材料分析的固定编码表。

依据：`d4fd7a65191a69909`，PDF p2–5、p9；`db67d8eb93aafb9e5`，PDF p3–4、p7–8。

### 路线 D：案例与其他方法衔接

案例可以探索构念与关系、解释已有定量结果、说明实际类型，或为形式模型提供情境。另一种方法承担与其资料相符的任务。两种方法的顺序和责任按真实设计分别说明，不能仅凭“混合研究”标签推定先后检验关系。

生成式 AI 文献先用六家企业案例构建框架，再形成理论模型与假设，最后用问卷及结构方程模型检验。未来只有案例材料时，可以借鉴其案例部分，不补写问卷检验。另一条方向是计量研究中的真实案例说明，案例和计量数据各自承担任务。

还可以先呈现定量结果，再用案例寻找未明机制。女性领导者研究在两项问卷研究后分析19个公开人物案例；成功、高认同案例的选择限制同时保留。章节顺序由案例在整体研究中的任务决定，不统一排成“案例在前、检验在后”。

三一研究先做探索性案例，再应用HMM进行形式模型演算。案例分析、参数赋值和模型演算分别说明；演算结果不改写成真实样本的因果效应检验。

依据：`d2d08a3e38f52ad70`，PDF p3、p6；`d81e63175332897b8`，PDF p5–6、p13注9；`df0c1b3388d78a839`，PDF p4–8；`def0476532e542a75`，PDF p1、p4–7、p9。案例接情景实验见 `dbc68c4def347d7b3`，PDF p11；案例接QCA见 `de5112afe45a51d69`，PDF p7。

### 路线 E：同一焦点案例中的嵌入单元

先画清焦点案例的整体边界与分析层次。基地、项目、团队、员工、被孵企业或合作关系，在选择理由和真实材料支持下可以成为嵌入单元；参与企业不自动成为同企业内部单位，也不自动成为相互独立的主案例。分别说明单元内、单元间以及单元与焦点整体的关系证据。

**章节骨架**：焦点整体问题 → 单元选择与关系 → 单元内行动 → 同维度比较 → 整体与单元之间的连接 → 讨论。

启迪之星研究以单平台内四个基地为嵌入单元，分别讨论资源行动、基地策略和总部保障。企业内部流动研究又把公司边界与员工层的流动、学习和人力资本变化分开。新案例不能仅凭企业整体业绩解释每个团队或员工的变化。

依据：`d53c9adc791e61d59`，PDF p3–4、p7；`d65c500f2ae80a7f1`，PDF p16。

### 路线 F：实践干预、行动与反思

明确研究者是观察者、参与者还是干预者。记录初始问题、介入动作、变化、反馈和反思；过程中的目标调整与失败也进入资料。

**章节骨架**：问题诊断 → 介入位置与材料 → 行动及调整 → 结果与未解决问题 → 理论反思与适用边界。

大兴机场论文按工程目标变化、整体性诊断、管理重构与理论反思展开。XP大学研究结合单案例、行动研究与建构扎根。不能因参考论文报告实践团队访谈，就把新案例的公开报道写成学术研究者访谈。

依据：`d99e72db1733a2b97`，PDF p4、p14；`d41abc06b836f2d65`，PDF p3、p5。后一篇文字由OCR恢复，关键方法摘录核对版面。

### 路线 G：理论推导后用案例展开或检视

先交代理论前提和推导，再说明案例用于解释什么、支持什么、留下什么疑点。模型中的假设与资料中的观察分别记录。

胜利牧业论文先将社会生态系统框架本土化并构建跨期博弈模型，再用治理过程解释关系与契约的调适。它与路线D中“先案例、后形式模型”的研究顺序不同。

依据：`d72f6f529a0652832`，PDF p5、p10。

### 路线 H：历史比较或既有案例的再分析

资料单位是历史事件或已发表案例时，写清纳入规则、原资料形成方式、比较维度和再分析步骤。既有研究的一次访谈，不能算作本研究再次开展的访谈。

45篇案例文献的质性元分析属于既有案例再分析。它提供检索、筛选、共同维度和跨案例整合的参考，不是45家企业自行调研的模板。

依据：`dee98e4968973d04c`，PDF p4–6。

### 有限用途：背景例证与附注案例

附注中的家庭说明、附录中的政策执行案例可以示范背景、类型或机制直观说明。其短篇结构不能作为完整质性研究的方法章与发现章范本。

依据：`d2befbcab385b7dd6`，PDF p19注7；`d343e1ba07e47593e`，PDF p19附录。纯实验、问卷或计量论文没有实际案例部分时，保留排除记录，不将它纳入案例模板。

## 5. 方法章节写什么

方法章节说明为什么这些材料和步骤能回答这个问题。

| 环节 | 具体内容 | 段落动作 |
| --- | --- | --- |
| 方法与问题匹配 | 解释对象、材料结构、需要追踪的过程或差异 | 说明设计理由 |
| 案例选择 | 典型性、对比关系、观察价值与资料条件 | 逐项说明，不只贴标签 |
| 资料收集 | 主体、时期、方式、数量、用途 | 给出来源表和实际记录 |
| 分析步骤 | 事件组织、编码、比较、理论迭代 | 让材料到概念的路径可追溯 |
| 解释检查 | 反例、不同来源、回访或替代解释 | 写实际做过的动作 |

**选择案例的改写句式**：选择【对象】并非只因其知名度，而是因为【特定现象/变化/比较关系】为观察【问题】提供了材料；同时，研究者实际取得了【资料条件】。

索菲亚研究的案例选择分别回应关系代表性、环境动态性、合作绩效与资料可获得性。其公开档案补充访谈中不便当面表述的冲突信息。多来源的具体互补作用比写一句“三角验证保证可信”更可审查。

依据：`d31e644b5640c4f4a`，PDF p5–7。

## 6. 两种材料条件，分别使用模板

### 混合材料条件

一手材料与公开资料可以承担不同任务：内部过程、当事人解释、可观察互动、公开事件与结果。逐项核查它们是否真的互补，是否来自同一主体，以及是否存在冲突。

引用受访者的认知说明时，接上对应行为与结果的证据。一个受访者说自己重视创新，不直接等于企业形成了创新能力。

### 公开材料条件

从资料可观察的事件、外部行动、关系安排和公开结果起步。方法段写真实获取的公开来源，不把公开访谈改写成研究者自行访谈。

内部决策、动机、隐性知识和未公开互动缺少资料时，调整问题或补充材料。模板的内部机制解释段不能只靠公司宣传填满。

训练语料提供了下列公开材料路径。它们证明这种设计确实出现，但不证明所有内部机制问题都能只靠公开材料回答。

| 公开材料路径 | 文献观察 | 未来案例的材料要求 | 边界 |
| --- | --- | --- | --- |
| 争议事件过程 | 专利战研究组合公告、法律文书、专利数据库、媒体与互联网档案，还原高通、苹果、英特尔的过程。`d420e4e402b2917b2`，PDF p2–3。 | 多主体、有日期的行动、争议文本与结果；保留事件版本。 | 行动可以观察，内部动机仍须单独证明。 |
| 公开网络与文本 | VR研究组合联盟数据与公开案例文本。`d66a7cb2a945dc992`，PDF p2–3。 | 明确网络节点、关系、时间和文本如何取得；把网络指标与文本解释对接。 | 网络关系不是受访者的真实认知。 |
| 公开演讲与媒体访谈 | 任正非媒体实录研究使用27次报道访谈。`d211d6313068812c7`，PDF p3–4。 | 记录采访者、日期、原媒体与转载关系；区分公开话语和实际行为。 | 作者称“一手”不能改写为用户自己采访。 |
| 平台日志与使用观察 | 微信研究组合版本日志、官方文件、书籍和公开演讲，并加入直接使用观察。`db95b0162f34e3485`，PDF p5。 | 保留版本、功能和观察记录；观察动作按真实执行填写。 | 使用观察不等于企业内部参与观察。 |
| 公开材料多案例编码 | 多团队系统研究整理9家企业的新闻、网站、公开访谈报道和著作，用于特征、模式与路径分析。`d973dde5bc3fb5be3`，PDF p5–9。 | 各案例保留共同维度、材料覆盖与纳入理由；记录与框架冲突的材料。 | 所读方法未报告研究者自行访谈；编码层次数不直接复制成新研究结果。 |
| 年报与公告事件链 | 亚太药业研究组合财务、股权和公告资料，核对四类行为的事件链。`dd82f522f9b3c42f8`，PDF p2–4、p8–9。 | 核对金额、口径、时点、行动主体与公告版本。 | 外部行为不自动证明当事人套利动机。 |

魔搭研究同时报告公开资料和“阿里内部资料”，其取得方式并非全部明确。因此不将整篇归为纯公开材料设计。奇点云研究把公开宣发本身作为身份塑造行为，同时还有访谈与观察。公开话语可以是研究对象，不能不加检验地成为业绩与机制的证明。

依据：`d49ac508028588020`，PDF p6；`d1c056e616309f865`，PDF p5。

**只有公开材料时的段落链**：定义可观察对象 → 说明公开材料取得与覆盖 → 建立多主体事件表 → 比较行动及变化 → 检查来源冲突 → 提出材料范围内的解释 → 明确内部过程缺口。新案例取得内部材料后，再决定是否扩大机制解释范围。

**混合材料时的段落链**：说明各来源分别回答什么 → 公开事件与内部描述对应 → 展示一致与冲突 → 说明补访/观察/档案核对的真实动作 → 形成解释。同期企业文件、回顾访谈与公开资料的用途可以不同。`d20fe28e58416519e`，PDF p5。

## 7. 案例分析段落：事实与解释配对

每个分析段落可以用以下检查顺序，实际写作时根据论证调整。

1. 本段解释什么？
2. 哪项事件、数字或引语支持它？
3. 作者怎样用概念定位或归纳这些事实？
4. 概念之间是什么关系？
5. 是否有反例或其他解释？
6. 本段把什么问题交给下一段？

**改写句式**：在【阶段/情境】中，【行动主体】采取了【具体行为】。材料【来源 ID】显示【事实/引语】。这一变化表现为【概念】，并通过【有证据的过程】连接到【结果】。与【对照情况】相比，【条件差异】说明该解释的适用范围。

材料不足的环节留下缺口，不为了套齐句式补造“过程”或“结果”。

## 9. 理论贡献段落：写清增加了什么

**段落链**：指定对话对象 → 概括原解释 → 给出本研究发现 → 说明新增条件、关系或过程 → 写边界。

**改写句式**：已有【领域】研究主要从【原解释】理解【对象】。本研究发现，在【条件】下，【关系/过程】呈现【变化】，从而补充了【具体解释内容】。这一解释适用于【材料支持的范围】。

贡献可以是解释条件、关系或过程的变化，不只是一句“丰富了某理论”。贡献也不是把发现列表、实践启示和政策建议放在一起。索菲亚贡献逐路与既有研究对话；部分跨刊论文更侧重结论与启示，使用时保留目标期刊与学科的差别。

依据：`d31e644b5640c4f4a`，PDF p15、p17；`d4fd7a65191a69909`，PDF p9。

## 11. 段落分布的使用方式

全文结构统计用于观察篇幅负担，段落卡片用于安排论证功能。自动提取的文本块不等于真实段落；未完成版面复核的数量与比例只作为候选统计。

模板安排以“本节必须解决什么问题”为起点：引言完成问题与对话；方法完成设计与证据条件；分析完成事实到解释；讨论完成理论关系与边界。不能只按统一比例把新案例切成几个章节。

逐文献章节标题、候选结构比例、块位置与人工关键段落记录分别保存在文本库和提取索引中。统计说明分母、纳入方法、自动估计与人工审阅的范围。配套《章节与篇幅参考》用训练示例展示不同章节配置；逐篇候选数值另存CSV，不把未知功能强行分类。

### 段落分布如何复用

以下是**本项目的写作建议**，不是从全量PDF人工清点出的固定段落数量。一个功能可以跨多个段落；同一段落也可以连结两个紧密动作。

| 位置 | 建议的功能顺序 | 分配与删改依据 |
| --- | --- | --- |
| 引言 | 现象/张力 → 研究意义 → 既有解释 → 特定不足 → 问题和路径 | 前四项材料不全时，保留待核查；不以大段行业背景代替问题。 |
| 理论部分 | 概念界定 → 解释对象与前提 → 解释之间的关系 → 本文观察方向 | 每条理论有后文用途；无用途的概念不增加篇幅。 |
| 方法部分 | 设计理由 → 案例选择 → 资料用途 → 分析过程 → 解释检查 | 各功能都对应真实程序；未执行的程序标为计划。 |
| 发现部分 | 节首问题 → 证据 → 概念 → 关系 → 小结/转场 | 按阶段、主题或比较单元重复；证据密度决定段数。 |
| 讨论部分 | 整合发现 → 与原解释相同之处 → 不同之处及其原因 → 边界 | 讨论不再重复全部案例故事。 |
| 结论部分 | 回答问题 → 理论增量 → 实践含义 → 局限与后续研究 | 理论增量有明确对话对象；实践含义连接具体行动者。 |

**阶段型配置示例**：用一段交代分期依据，随后每个阶段围绕相同维度安排证据和解释，最后用跨阶段段落解释变化。不能逐年记流水账，也不能以“第一阶段”自动证明某机制成立。

**主题型配置示例**：节首先指出解释任务；各子节分别证明条件、行动与关系；节尾把未回答的问题交给后文。索菲亚在p8从已有资源基础转向尚未解释的能力构建问题，是这种转场的训练依据。

**比较型配置示例**：案例介绍只保留比较所需背景；各案例内证据采用相同维度；跨案例段落负责相同、差异和边界，而不是重复介绍各企业。依据：`d4fd7a65191a69909`，PDF p3–5、p9。

逐段写作时，调用《段落与理论卡片库》。段落卡负责局部论证，方法路线负责全文组织，两者同时检查。

## 12. 复用时的最短操作路线

材料与事实表 → 过程时间线或边界与状态表 → 候选研究问题 → 理论作用表 → 分析设计 → 证据与解释矩阵 → 详细提纲 → 分节草稿 → 一致性复核。

已有研究问题时从材料匹配与理论检查开始；已经完成分析时从详细提纲开始。完整步骤、阶段输出与缺口动作见《AI执行流程》。

### 发现章节模板

> 本节回答【子问题】。材料【来源和定位】记录【关键事实】。在【可观察条件】下，【行动主体】做了【行为】。这些证据表现出【概念及其定义】。与【前期/其他单元/反例】比较，【差异】支持【关系解释】，但【替代解释或缺口】限制了这一判断。下一节进一步解释【未解决问题】。

### 理论贡献模板

| 原解释 | 本研究发现 | 增加的解释 | 证据 | 适用边界 |
| --- | --- | --- | --- | --- |
| 【真实理论及其主张】 | 【案例支持的关系/过程】 | 【条件、层次、作用方向或过程的增量】 | 【来源与页段】 | 【材料不支持的范围】 |

## 14. 用前自查

- 引言的每个问题，在发现或讨论中都有回答。
- 方法描述区分作者报告、当前计划与真实执行。
- 每个构念都有材料依据；每条模型关系都有对应解释。
- 每个资料标签反映实际取得方式；内部资料不改称公开。
- 原文观察、项目建议、改写句式与新案例事实分别标记。
- 参考案例的阶段数、编码层次、理论名称与结论不直接搬入新案例。
- 对工商管理论文的建议，区分公共治理、农业社会问题与政策解释的边界。
- 留出验收、模拟演练与真实自有案例验证分别报告。

## 15. 增量学习补充：选择真正改变执行的条件分支

本节基于新增训练的具体论证动作细化v1。主路线仍为A–H；以下是资料判断或条件适配，不要求每篇同时启用。文献观察、项目建议和未来新案例事实分别记录。所有页码为从1开始的PDF页码。

### 15.1 在事实表增加材料身份和过程状态

材料“包含某件事”不等于该事已经发生。平台方案、公开目标、实际使用日志、当事人陈述、规范条文、协商评分、模型预测与作者建议分别登记。把材料形成时点、事件发生时点、回顾范围和研究覆盖终点同时写清。2022年访谈回顾1980年代不能登记为1980年代现场观察。依据：`d71c74fecc947421d` p3；`df8a0c52af0e287a4` p4。

| 材料身份 | 可以直接登记 | 不能直接推定 |
| --- | --- | --- |
| 目标/设计 | 打算达到什么、预设怎样安排 | 方案已运行、目标已达到 |
| 行动/观察记录 | 谁在什么时点做了什么、记录了什么变化 | 未观察环节或独立因果效应 |
| 参与者陈述 | 该主体的判断、经历或表述 | 全体一致、陈述客观成立 |
| 规范/政策文本 | 在对应时点规定或提倡什么 | 实际执行、所有主体受益 |
| 协商参数/评分 | 谁按什么程序给出什么输入 | 总体偏好、客观测量或随机分配 |
| 条件预测/模拟 | 在假设与参数下输出什么 | 真实未来、现场实际结果 |
| 诊断/方案建议 | 作者提出的解释和行动 | 已经实施及其效果 |

**过程状态字段**：已发生、进行中、未实施、资料未覆盖。状态附日期与来源；“资料未覆盖”不等于现实中未发生。对完整模型的每个环节分别登记当前证据，不从图形完整推定整个过程已验证。

平台论文先展示功能架构，再描述使用和协同不足；参与式建模论文把访谈/研讨转成评分输入，再做未来50年的情景模拟。这两种材料可以组合，但不得混淆证据身份。

训练依据：`d84dde3a9f249ecc4` p3–6；`df9bf7d4e9d1391f7` p4、8；空间现状与在建对象区分见 `d4cd47352d0136754` p4。配套P27。

### 15.2 案例入口先查对象和论证任务

研究对象可以是组织、关系、实践、地区、家庭、历史事件或具体文本/实物系统，未必是企业。但必须交代案例边界、可观察状态/行动与用于论证的材料。具体地区诊断不因使用数值就失去案例身份；跨地区抽样均值也不因题名写“为例”自动成为质性案例。符号/实物研究中，材料内容、理论解读、受众反应与经济效果分别取证；707标牌不是707企业，其表达不直接证明游客幸福。局部依据：`d805f3d72f572e0c8` p3、6。

| 正文实际任务 | 模板动作 |
| --- | --- |
| 具体对象的行动、状态或互动分析 | 按A–H及真实资料选择；不强制逐年过程叙事 |
| 同一地区的指标诊断+实际对象/访谈解释 | 可用诊断条件分支；保留描述性证据和地域边界 |
| 抽样家庭/省份的均值、回归、聚类或预测，没有具体对象案例论证 | 保留定量方法身份；不扩写为多个独立质性案例 |
| 人工参数生成的优化算例 | 标记数值算例；计算表现不改成现场实施效果 |
| 文献中的方法介绍、被引作者田野或制度概念评述 | 核验主语；只借局部表达，不称当前研究执行 |

### 15.3 接触便利、取样层次与比较理由分开

能够进入某村或企业说明访问条件，不直接说明该对象具有理论代表性。地点、组织、家庭、员工、事件和受访者分别记录进入规则；第一层等距或随机选择不能替后续典型对象选择保证总体代表性。

家庭研究在方便选村后从54户候选中按关系类型取三户；就业研究先等距选乡镇，再由政府协助筛选改善典型。未来Agent必须把每层程序和正面选择限制分开写，而不是概括成“随机多案例”。案例间可比较性来自共同解释任务、维度及覆盖条件，不来自数量本身。文本也保留纳入/排除规则与分母；旧研究删除“不合理”诉求的判断不能自动照抄为新研究删反面材料的规则。工单训练例：`dac0d9b96226db892` p4–6。

训练依据：`d913240ff9b60cf59` p5；`dce7918d76a39b159` p7–8。配套P30。

### 15.4 结果按主体、口径与未达成部分组织

同一安排可以提高平台效率，同时让商户或家庭承担劳动、费用与进入障碍。组织获利、直接分红、间接受惠、公共福利、认同与可迁移技能不是同一种结果。每项结果保留主体、分母、时期、资料身份和预期/意外性质。

合作社办企业研究区分组织产权、成员控制与收益方式，扩展调查只说明分布；就业研究保留认知改善而生产技能未形成的不对称结果。不能因为一项目标达成就把全部目标写成“赋能成功”，也不能由成功样本反推成功必要条件。

训练依据：`d66c7540ad1e73c81` p13、15、17–18；`dce7918d76a39b159` p13、17；规范损益见 `dfed1e8e34da31455` p18。配套P29。

### 15.5 参与位置与材料生成：研究者角色反思

当研究者自身的参与影响资料形成时，在F的身份说明之外，记录进入场域、角色变化、访问关系、对方如何使用研究者及其材料影响。现场观察、参与者解释、研究者解释与项目宣传分别保存。

泰北村落民族志中，研究者经历游客、教师、志愿者角色，并成为项目成功表征的一部分。它提示资料不是脱离互动的中性容器。反思不能自动证明受访者全部失真，也不能把参与研究改写成有对照的行动干预。

该民族志提供明确位置反思示例，不宣布所有企业案例均应采用民族志。工作、咨询、共同开发或志愿身份实际影响材料时，也登记角色、互动、可见范围和补证条件；不借身份接近宣布研究者实施了干预。智慧社区研究报告作者成员在街道/社区工作近6个月，但没有报告操控改造，作为接入条件例，不能当同等反思或实验控制的证据。训练依据：`d2cf9c69404636850` p7；`d71addbedfc4cebc5` p4–5。配套P24。

### 15.6 过程追踪：先有可观察预期，再判断证据作用

普通时间线回答事情的次序；机制追踪还必须说明某证据对机制及竞争解释有何区分作用。计划或实际采用此方法时，增加以下矩阵：

| 机制部件 | 对应行动/可观察预期 | 竞争解释及其预期 | 实际证据与来源 | 未观察的原因 | 否定/确证作用 | 当前主张 |
| --- | --- | --- | --- | --- | --- | --- |
| 按实际假说 | 先提出可观察含义 | 明确替代过程 | 事件、文书、陈述或痕迹 | 过程没发生/材料未覆盖，分别判断 | 解释为什么能区分 | 支持线索/待检验/不足 |

训练论文区分模式、次序、痕迹、记述证据，并另按确定性与独特性讨论检验力度。未来复用时借其任务分工，不能仅给一条事后引语贴检验标签。证据没有出现是否否定机制，还取决于该痕迹原本应否出现和资料能否观察；某证据出现是否支持机制，还须比较其他解释也产生它的可能性。

同一结果、先后关系或多个转述来源不单独证明机制。当前模板不核实作者所报告机制的真实性，不将全部案例称为完成因果检验。

训练依据：`d8761feea2807270f` p15–16。配套P26/T13。

### 15.7 规范与制度建议：经验、标准、方案三层论证

涉及公平、公共性、权利、职业伦理或制度方案时，经验发现回答“发生了什么、如何形成”，规范标准回答“以什么判好坏”，建议回答“依据这些前提谁可以怎样改变”。三层互相连接，却不能相互替代。

**段落链**：经验事实及限制 → 评价标准及其来源 → 各主体损益和标准冲突 → 可选方案与约束 → 推导理由 → 实施或效果尚未验证的范围。

规范来源可以是文章明确采用的价值前提、适用制度或真实理论论证。涉及具体法律/政策适用时，按研究时点核对真实原文、适用主体和版本；没有依据时保留待核查，不根据旧论文直接宣布新方案合法适用。它是特定论证任务，不是每篇管理研究增加法律清单。

集体经济的公平标准、成员资格与公共收益不能换成普通公司的股东收益；公共目标也不能代替工商管理论文的明确理论对话。某个案取得绩效不单独推出某制度普遍最优。

公共治理材料再区分规范要求、实际行动、主体理解、具体结果与作者评价。老任调解研究将文书授权、当事人认同、关系修复和现场教育分别叙述；未来复用时分别找证据，接受或有效不能替代合法性依据，作者称有预防功能也不自动证明长期预防效果。本项目只学习其论证分工，不核实当前法律适用。依据：`d87c0fc5bb7950a93` p2、6。

训练依据：`def2a0acb3ed47bcc` p9、12；`da513ae35322e2666` p17；`dfed1e8e34da31455` p18；历史工程代价与规范经验见 `de96401503e246a78`。配套P25/T12。

**专业法教义的局部边界。** 规范三层表能组织案例事实、标准与建议，但不替代物权/债权、权利客体或立法体系的专业推理。宅基地有偿使用文献的试点比较可借局部事实组织，其核心权利构造仍属跨学科例外；拟议经营权不改成现行已有权利。训练例：`db70bd227ab300683` p1–3、6。此类适配不能宣称完整工商机制模板覆盖。

### 15.8 实践诊断与局部规划适配

当核心任务是识别现状障碍并生成行动方案时，先说明目标/基准及其口径，再展示偏离，结合具体对象证据解释障碍，最后比较备选动作与约束。不要先列万能建议，再从案例中寻找装饰性引语。

**诊断提纲**：问题与评价对象 → 基准和资料条件 → 现状差距 → 对象内障碍证据 → 备选方案及取舍 → 未实施/未验证结果 → 理论或实践贡献范围。

云龙县论文用年鉴及访谈诊断产业与就业错配，但产值与本地就业归属有分母限制；平台论文以实际使用不足反思既有功能设计。诊断中的描述指标不等于净因果效应，建议的可行性和实施结果分别给证据。

训练依据：`df47fd0061fa637c3` p2、7；`d84dde3a9f249ecc4` p6。配套P28。

**空间规划局部适配**：现状单元 → 空间/规范约束 → 指标或访谈判断 → 对应设计动作 → 待验证结果。杜陵研究把未入住小区排除出现状共生单元；规划对象不能提前记成已运行对象。此例属于跨学科规划任务，不新增工商管理通用主路线。依据：`d4cd47352d0136754` p3–4。

社会空间还涉及使用、成员纳入、经营机会和收益分配，不只是地理面积或企业场所。袁家村空间转型研究保留本地/外来者冲突和权利安排；未来Agent分别记录空间边界、主体、使用/分配关系与规范评价，不以游客量代替空间公平。局部依据：`d29cee959c91eae60` p7、10、17。
